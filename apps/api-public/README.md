# SwiftShip AI — Public API

The merchant-facing, versioned, rate-limited REST API for SwiftShip AI. The wire surface (routes, request/response shapes, security schemes) is generated by `tsoa` from the controllers under `src/controllers/`. On every `nx build api-public` the tsoa CLI emits `src/generated/openapi.json`, which is the source of truth for the 3 official SDKs.

## Quick start

- **Landing page** — `http://localhost:3000/` (or `http://localhost:3001/` when `API_REST_PORT=3001`)
- **Swagger UI** — `http://localhost:3000/docs/v1/`
- **OpenAPI spec** — `http://localhost:3000/docs/v1/openapi.json`
- **GraphQL playground** — `http://localhost:3000/graphql`

## Authentication

Every authenticated request must include an `X-Swiftship-Api-Key` header. The key is per-tenant; issue one in the admin portal under **Settings → API keys**.

```
X-Swiftship-Api-Key: sk_test_...
```

The header is required on every endpoint except:

- `GET /v1/track/:awb` — customer-facing tracking lookup (no merchant auth)
- `GET /health`, `GET /health/ready` — liveness / readiness probes
- `GET /docs/v1/` — Swagger UI
- `GET /docs/v1/openapi.json` — OpenAPI spec

If the header is missing on a protected endpoint you get a `401 Unauthorized`. If the header is present but the key is unknown / revoked you get a `403 Forbidden`.

## Base URL

| Environment | Base URL                         |
|-------------|----------------------------------|
| Local dev   | `http://localhost:3000`          |
| Staging     | `https://api-staging.swiftship.in` |
| Production  | `https://api.swiftship.in`       |

All paths below are relative to the base URL and are versioned under `/v1/`.

## Rate limits

Per-tenant throttling. The bucket size depends on the tenant's tier. Response headers on every request:

- `X-RateLimit-Limit` — bucket size for the current tenant tier
- `X-RateLimit-Remaining` — requests left in the current window
- `X-RateLimit-Reset` — seconds until the window resets

**Note**: By default, all tenants start at 120 req/min (Starter tier).

| Tier        | Requests / min | Burst  |
|-------------|----------------|--------|
| Starter     | 60             | 60     |
| Growth      | 300            | 300    |
| Pro         | 1000           | 1000   |
| Enterprise  | 10000          | 10000  |

When the bucket is empty the API returns `429 Too Many Requests` with a `Retry-After` header. The default tier for new tenants is **Starter**.

## SDKs

Three official SDKs are generated from `src/generated/openapi.json` on every build:

| Language | Package                   | Install                            |
|----------|---------------------------|------------------------------------|
| Node     | `@swiftship/node`         | `npm install @swiftship/node`      |
| Python   | `swiftship`               | `pip install swiftship`            |
| PHP      | `swiftship/swiftship`     | `composer require swiftship/swiftship` |

### Node.js (`@swiftship/node`)

```ts
import { Configuration, OrdersApi } from '@swiftship/node';

const config = new Configuration({
  basePath: 'https://api.swiftship.in',
  apiKey: process.env.SWIFTSHIP_API_KEY,
});

const orders = new OrdersApi(config);

const list = await orders.listOrders({ status: 'CREATED', limit: 25 });
console.log(list.orders);

const created = await orders.createOrder({
  externalId: 'shopify-1029',
  customerName: 'Aman Vats',
  customerPhone: '+919999999999',
  destinationPincode: '110001',
  paymentMethod: 'PREPAID',
  weightGrams: 500,
  declaredValuePaise: 49900,
  items: [
    { sku: 'TS-BLK-M', name: 'Black T-shirt M', quantity: 1, unitPricePaise: 49900 },
  ],
});
console.log(created.id);
```

### Python (`swiftship`)

```python
import os
from swiftship import Configuration, OrdersApi

config = Configuration(
    host="https://api.swiftship.in",
    api_key={"X-Swiftship-Api-Key": os.environ["SWIFTSHIP_API_KEY"]},
)

with OrdersApi(config) as orders:
    listing = orders.list_orders(status="CREATED", limit=25)
    for order in listing.orders:
        print(order.id, order.external_id)

    created = orders.create_order({
        "externalId": "shopify-1029",
        "customerName": "Aman Vats",
        "customerPhone": "+919999999999",
        "destinationPincode": "110001",
        "paymentMethod": "PREPAID",
        "weightGrams": 500,
        "declaredValuePaise": 49900,
        "items": [
            {
                "sku": "TS-BLK-M",
                "name": "Black T-shirt M",
                "quantity": 1,
                "unitPricePaise": 49900,
            }
        ],
    })
    print(created.id)
```

### PHP (`swiftship/swiftship`)

```php
<?php
require __DIR__ . '/vendor/autoload.php';

use SwiftShip\Sdk\Client;
use SwiftShip\Sdk\Configuration;

$config = Configuration::getDefaultConfiguration()
    ->setHost('https://api.swiftship.in')
    ->setApiKey('X-Swiftship-Api-Key', getenv('SWIFTSHIP_API_KEY'));

$client = new Client($config);

$orders = $client->getOrdersApi();

$listing = $orders->listOrders(['status' => 'CREATED', 'limit' => 25]);
foreach ($listing->getOrders() as $order) {
    echo $order->getId() . ' ' . $order->getExternalId() . PHP_EOL;
}

$created = $orders->createOrder([
    'externalId' => 'shopify-1029',
    'customerName' => 'Aman Vats',
    'customerPhone' => '+919999999999',
    'destinationPincode' => '110001',
    'paymentMethod' => 'PREPAID',
    'weightGrams' => 500,
    'declaredValuePaise' => 49900,
    'items' => [[
        'sku' => 'TS-BLK-M',
        'name' => 'Black T-shirt M',
        'quantity' => 1,
        'unitPricePaise' => 49900,
    ]],
]);
echo $created->getId() . PHP_EOL;
```

## Endpoints

The full list is in the Swagger UI at `/docs/v1/`. Highlights:

| Method | Path                        | Notes                                    |
|--------|-----------------------------|------------------------------------------|
| GET    | `/v1/orders`                | List orders (filter by status, dates)    |
| POST   | `/v1/orders`                | Create order (auto-picks a carrier)      |
| GET    | `/v1/orders/{id}`           | Fetch order                              |
| GET    | `/v1/orders/total-sales`    | Aggregate sales                          |
| GET    | `/v1/orders/counts-by-status` | Counts grouped by status                |
| GET    | `/v1/shipments`             | List shipments                           |
| POST   | `/v1/shipments`             | Create shipment                          |
| GET    | `/v1/shipments/{id}`        | Fetch shipment                           |
| GET    | `/v1/shipments/{id}/label`  | Download shipping label (PDF)            |
| GET    | `/v1/track/{awb}`           | Public tracking — no auth                |
| POST   | `/v1/rate-shop/rank`        | Get ranked rate quotes                   |
| GET    | `/v1/carriers`              | List carriers                            |
| GET    | `/v1/shipping-rates/cheapest` | Cheapest rate for a route               |
| POST   | `/v1/returns`               | Create return                            |
| POST   | `/v1/webhooks/shopify`      | Shopify webhook receiver (HMAC verified) |

## Errors

All error responses use the same shape:

```json
{
  "error": "ValidationError",
  "message": "destinationPincode must be 6 digits",
  "details": [
    { "field": "destinationPincode", "code": "pattern" }
  ]
}
```

Common status codes:

- `400 Bad Request` — malformed JSON or failed validation
- `401 Unauthorized` — missing `X-Swiftship-Api-Key`
- `403 Forbidden` — key revoked or wrong tenant
- `404 Not Found` — resource does not exist
- `409 Conflict` — duplicate `externalId`, etc.
- `422 Unprocessable Entity` — business rule violation (KYC not verified, etc.)
- `429 Too Many Requests` — bucket exhausted
- `500 Internal Server Error` — bug, please open a support ticket

## Development

```bash
# Generate the spec + routes (idempotent)
npx tsoa -c apps/api-public/tsoa.json

# Build everything
npx nx run api-public:build

# Run locally
npx nx serve api-public
# → http://localhost:3001/
# → http://localhost:3001/docs/v1/
```
